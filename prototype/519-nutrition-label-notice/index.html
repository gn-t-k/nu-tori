栄養成分表示の知らせと印を、どこにどう出すか

表示が写った市販品は、表示の値で記録するようになる（推定のしかたはユーザーが選ばず自動で切り替わる）。そのとき、(1) 表示でも撮れることを知らせる場所と出し方、(2) 表示の値を使った材料にそうと分かる印の見た目と置き場所を決めたい。下のバーで、知らせ（A〜D）と印（1〜3）を別々に切り替えられる。

守る線（ADR-0015）: 裏の表示を撮るようユーザーに頼まない。「表示も撮ってください」と促す案内と、表示を撮る専用のボタンは、どの案にも入れていない。点線で囲んだところが、案ごとに変わる場所。

語: 知らせる = ここでは「表示でも撮れる」と伝える文のこと。GLOSSARY の「知らせ」（タイムラインに出すカード）と区別するため、カードの形をとる案だけを「知らせのカード」と書く。材料の出どころ = GLOSSARY の「栄養の出どころ」（栄養成分表示・成分表・推定）。

      開発者に選んでもらうこと

      選ぶこと

      1. 知らせ: A〜D のどれにするか（組み合わせも可。例: C を土台に B を足す）
      2. 印: 1〜3 のどれにするか。どの画面まで印を上げるか（料理の画面だけ／食事の画面まで／タイムラインまで）
      3. 印の文言: 「表示」でよいか（GLOSSARY は「栄養成分表示」。短くした「表示」を印の語として足すか）
      4. 表示の材料の量（1 食・1 袋）は推定したままなので「推定」の印も付く。「表示」と「推定」が並ぶのをそのままにするか、表示の材料では「推定」の印を出さないか
