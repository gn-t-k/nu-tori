nu-tori プライバシーポリシー

制定日: 2026年9月29日　改定日: 2026年9月30日

村上玄徳（以下「運営者」）は、iPhone アプリ「nu-tori」とそのサーバー（以下あわせて「nu-tori」）で扱う情報について、このプライバシーポリシーを定めます。

1. 集める情報と集め方

アカウント

  • Sign in with Apple でサインインしたときに Apple から受け取る、あなたを表す識別子
  • nu-tori があなたのアカウントに振る ID（以下「アカウント ID」）
  • 最初にサインインに成功した時刻と、そのときの端末のタイムゾーン、そこから決めた使い始めた日
  • サインインを続けるためのセッションの情報と、Apple の認可の情報（暗号化して保存します）

名前とメールアドレスは、Apple から受け取っても保存しません。

記録

あなたがアプリで記録したものと、それをもとに nu-tori が作ったものです。

  • 食事: 時刻、料理と材料の名前、量、栄養の値
  • 体重と体脂肪率
  • 目標と、推定消費量・1日の目安などの計算の結果
  • 書いて送った文章と、それへの返事
  • 記録した時刻のタイムゾーン、体重を記録するいつもの時刻

写真

食事を撮った写真と、写真ライブラリから選んだ写真は、元の大きさのものを iPhone のアプリの中に置きます（iPhone のバックアップには含まれます）。サーバーには、長い辺を 1024 ピクセルに縮め、撮った場所などの付帯情報を消したものを送って保存します。写真ライブラリのほかの写真には触れません。

ヘルスケアの情報

あなたが許可したときだけ、iPhone のヘルスケアと次の情報をやりとりします。許可は iPhone の設定またはヘルスケアアプリでいつでも変えられます。

  • 読むもの: 体重、体脂肪率、身長、生年月日、性別、歩数、摂取エネルギー
  • 書くもの: nu-tori で記録した体重と、食事の栄養

読んだもののうち、サーバーに保存するのは、ほかのアプリで記録した体重と体脂肪率だけです。nu-tori を使い始める前の分を含めて取り込み、記録したアプリの名前も一緒に保存します。

身長・年齢・性別・歩数と、nu-tori を使い始める前の摂取エネルギーは、初めて目標を立てるときの計算のためにだけ送り、計算に使ったら保存せずに捨てます。ヘルスケアから読めないときにアプリで入れた身長・年齢・性別・活動量も、同じように扱います。

不具合の報告

アプリやサーバーで起きたクラッシュとエラーについて、エラーの内容、直前の操作と通信の記録（通信先の URL を含みます）、アプリを使った回の始まりと終わり、機種・OS とアプリの版・タイムゾーンなどの端末の情報、端末を区別する符号、アカウント ID を集めます。記録の中身（写真、文章、料理と材料の名前、体重・体脂肪率・栄養の値）は含めません。

利用状況

開いた画面、行った操作、推定や同期の件数・かかった時間・成否を、アカウント ID と一緒に集めます。機種、OS とアプリの版、画面の大きさ、言語の設定、タイムゾーンなどの端末の情報、端末を区別する符号も付きます。記録の中身は含めず、健康に関わる値は、値そのものではなく、前との差や率、条件に当たったかどうかだけを送ります。IP アドレスは捨て、位置は付けません。

サーバーからも、同期で受け付けなかった書き込みの種類と理由、iPhone にまだ送っていない記録の件数とその中でいちばん古いものの経過時間を、アカウント ID と一緒に送ります。書き込みの中身（体重の値など）は含めません。送るのを止めると、サーバーからも送りません。

同期の記録

記録を iPhone とサーバーで同期するたびに、次のことを記録します。

  • 要求ごとに: 端末を区別する ID、アプリと OS の版、端末のタイムゾーン、iPhone にまだ送っていない記録の件数とその中でいちばん古いものの経過時間、送っていない写真の数、受け取った日時
  • 受け取った書き込みごとに: 書き込みの ID、種類、対象の記録の ID、結果（受け付けなかったときはその理由）。体重などの記録の中身は、この記録には含めません（記録として別に保存します）
  • ヘルスケアで元のデータが消えた体重記録を消したとき: 消した記録の ID を、消したことの印として残します。ほかの端末に消えたことを伝え、消えた体重を同期で生き返らせないためです

サーバーの要求の記録

サーバーへの要求ごとに、次のことを記録します。要求の本文（記録の中身や写真）は記録しません。

  • nu-tori が書き出すもの: 要求の ID、アカウント ID、呼んだ機能、結果、エラーの種類、かかった時間

あわせて、サーバーを動かす Cloudflare が、要求ごとに次のことを自動で記録します。

  • 要求: 日時、URL、方法（GET など）、結果の状態、処理にかかった時間
  • 接続元: IP アドレス、IP アドレスから推定した位置（国、大陸、地域、市、郵便番号、緯度と経度、タイムゾーン）、回線の事業者（AS 番号と名前）
  • 通信: 要求のヘッダー（アプリと OS の種類と版を表す文字列、言語の設定、受け付けるデータの形式など。サインインを続けるためのセッションの情報は伏せて記録されます）、通信の方式と暗号の種類、TLS の接続の情報、通信の往復にかかった時間、つないだ Cloudflare の拠点、ボットかどうかの判定

問い合わせ

問い合わせのフォームに書いた内容と、返事の送り先として書いたメールアドレス（任意）を受け取ります。アプリから開いたときは、アカウント ID も受け取ります。

2. 使い道

集めた情報は、次のことにだけ使います。

  • 記録を保存し、あなたの iPhone に表示・同期する。機種を変えたときに記録と写真を戻す
  • 写真と文章から、料理と材料、量、栄養を推定する
  • 体重の傾向、推定消費量、1日の目安、目標の案と進み具合を計算する
  • 書いて送った文章に返事をする
  • 体重の記録を忘れたときに通知する
  • ヘルスケアと記録をやりとりする
  • あなたであることを確かめ、不正な利用や使いすぎを防ぐ
  • 不具合を見つけて直す。同期が遅れていないかを、同期の記録で確かめる
  • 利用状況を集計し、nu-tori を良くする。推定消費量の計算と食事の推定がどれだけ当たっているかを確かめて直すために、体重や食事の値の前との差や率、推定の量を直した割合を集計する
  • 問い合わせに答える

集めた情報を、広告に使うことも、売ることも、ほかのアプリやウェブサイトの情報と結びつけてあなたを追跡することもしません。ヘルスケアの情報は、上の nu-tori の機能と、その精度を上げるためだけに使います。

3. 外部に送る情報

nu-tori は、次の会社のサービスを使って情報を保存・処理します。どの会社も米国の会社です。

会社とサービス送る情報と使い道
Cloudflare, Inc.（サーバー、データベース、写真の保存、要求の記録） アカウント、記録、写真の縮小版、要求の記録を保存し、処理します。データはアジア太平洋の拠点に置くよう指定していますが、保存と処理の国は保証されません。
Anthropic, PBC（AI のモデル「Claude」）

食事の推定のために、写真の縮小版、書いて送った文章と送った日時、直した・足した料理の名前を送ります。

返事を作るために、書いて送った文章とその会話の直近のやりとり、日時と、次の記録を送ります: 目標、1日の目安、推定消費量と直近の見直しの結果、今日の食事（時刻、料理の名前、量、栄養）、直前 7 日の日ごとの合計、体重の傾向と最後の体重（ヘルスケアから取り込んだ体重を含みます）。会話に病気などのことを書いたときは、それも送られます。写真、材料の細目、身長・年齢などの身体のデータ、ほかの会話は送りません。

不正な利用を見分けるために、アカウント ID を元に戻せない形に変えた値を添えます。処理は米国ほかの国で行われることがあります。
TypeSafe AI, Inc.（AI のモデル「Jev」。Cloudflare を通して使います） 書いて送った文章が食事か会話かを見分けるために、文章を送ります。TypeSafe は米国でサービスを動かしています。
Functional Software, Inc.（不具合の報告のサービス「Sentry」） 不具合の報告を送ります。データは EU（ドイツ）に保存します。
PostHog, Inc.（利用状況の集計のサービス「PostHog」） 利用状況を送ります。データは EU（ドイツ）に保存します。
Google LLC（問い合わせのフォーム「Google フォーム」） 問い合わせのフォームに書いた内容、メールアドレス、アカウント ID を受け取ります。

各社が講じる措置と、各社が自ら使う範囲

Google と TypeSafe を除く各社とは、利用規約とデータの処理の契約で、nu-tori から受け取った情報を nu-tori の指示の範囲で処理し、安全に管理することを定めています。そのうえで、各社が自らの目的で使う範囲は次のとおりです。契約を結んだ各社は、ここに書いた範囲のほかは、このポリシーと同等に情報を守ります。TypeSafe と Google は、それぞれが公表する方針の範囲で扱います。

  • Cloudflare: AI のモデルの学習とサービスの改善に使いません。グローバル CBPR の認証を受けています
  • Anthropic: AI のモデルの学習に使いません。利用規約の違反を疑ったものは、その判断のために残します（下の 5）
  • TypeSafe: nu-tori は Cloudflare を通して使うので、TypeSafe と直接の契約はなく、Cloudflare のデータの処理の契約も TypeSafe での処理には及びません。TypeSafe は、受け取った文章を AI のモデルの学習に使わないと定めています。不正の監視と、サービスの状態を測るために使うことがあります
  • Sentry: あなたを識別できる形で製品の改善に使うことは断っています。識別できない形では、Sentry の分析と製品の開発に使われます
  • PostHog: AI のモデルの学習に使うことは断っています
  • Google: 問い合わせの内容は、Google のプライバシーポリシーに従って扱われます

不具合と利用状況の分析に使う AI

運営者は、不具合の原因を調べるのに Sentry の AI の機能を、利用状況を集計するのに PostHog の AI の機能を使います。そのため、不具合の報告と利用状況（ヘルスケアの体重から出した値の差を含みます）は、次の会社でも処理されます。どの会社も、Sentry と PostHog の委託先として、その契約に従って処理します。

  • Sentry の委託先: Anthropic と OpenAI（米国）
  • PostHog の委託先: OpenAI、Google、Anthropic（米国）、Microsoft（米国とドイツ）、Cloudflare（世界の拠点）

Sign in with Apple とヘルスケアは Apple のしくみです。Apple による情報の扱いは、Apple のプライバシーポリシーに従います。

外国にある第三者への提供について

上の会社はどれも米国にあります。nu-tori は、個人情報の保護に関する法律にいう外国にある第三者への提供として扱い、サインインの画面であなたの同意を得たうえで、これらの会社に情報を送ります。Google には、問い合わせのフォームの冒頭の案内を読んで送っていただいたことで、同意を得たものとします。

  • 国の名前: アメリカ合衆国
  • その国の個人情報の保護の制度: 連邦の法律として、個人情報の保護を包括的に定めた法律はありません。州の法律（カリフォルニア州の消費者プライバシー法など）や分野ごとの法律があります。米国は APEC の越境プライバシールール（CBPR）システムに参加しています。詳しくは個人情報保護委員会の「外国制度（アメリカ合衆国）」をご覧ください。
  • 会社が講じる措置: 上の「各社が講じる措置と、各社が自ら使う範囲」のとおりです。

4. 同意と、その取り消し

サインインの画面で、記録と写真を上の会社のサービスで保存・処理すること、AI に送ること、不具合の報告と利用状況を送り、その分析にも AI を使うことに同意していただいてから、nu-tori を使い始めます。同意の前に、上の 3 の外国の制度と各社の措置をご確認ください。

  • 利用状況: アプリのアカウントの画面で、送るのをいつでも止められます。止める前に送った分は、下の 5 の期間まで残ります
  • ヘルスケアとのやりとり: iPhone の設定またはヘルスケアアプリで、いつでも許可を変えられます
  • それ以外（保存、AI への送信、不具合の報告）: nu-tori の働きに欠かせないため、取り消すにはアカウントを削除してください

5. 保存する期間と削除

アカウントの情報、記録、写真の縮小版、同期の記録は、あなたがアカウントを削除するまで保存します。食事を消すと、その写真もアプリとサーバーから消えます。ほかの情報は、次の期間が過ぎると消えます。

  • サーバーの要求の記録: 7 日
  • 不具合の報告（Sentry）: 30 日（Sentry の使い始めの試用の期間に届いたものと、Sentry のバックアップは 90 日）
  • 利用状況（PostHog）: 1 年
  • Anthropic に送った情報: 30 日以内（Anthropic が利用規約の違反を疑ったものは最長 2 年、その判断の結果は最長 7 年）
  • TypeSafe に送った文章: TypeSafe が必要とするあいだ（日数は定められていません）
  • 問い合わせの内容: 対応に要るあいだ。消してほしいときは問い合わせてください

アプリのアカウントの画面からアカウントを削除すると、その場で次のことを行います。電波がないときは削除できません。

  • サーバーのアカウントと記録と写真の縮小版と同期の記録を消す
  • Apple での Sign in with Apple の認可を取り消す
  • PostHog に送った利用状況を消すよう依頼する（PostHog が週末にまとめて消すため、最長で1週間ほどかかります）
  • iPhone の中の記録と写真を消す

削除のあとも、障害に備えたサーバーのバックアップには最長 30 日残ります。上の期間で消えるものは、削除のあとも、その期間が過ぎるまで残ります。

ヘルスケアに書き込んだ体重と栄養は、あなたのヘルスケアのデータとして残ります。ヘルスケアアプリで消せます。

Apple のアカウントを削除したことが Apple から知らされたときも、サーバーの分を同じように削除します。iPhone の設定で nu-tori の Sign in with Apple の利用をやめたときは、サインインが切れますが、記録は消えません。同じ Apple のアカウントでサインインし直すと、元の記録に戻れます。

6. 安全のための措置

  • 通信はすべて暗号化します。サーバーのデータベースは、保存するときにも暗号化されます。Apple の認可の情報は、さらに運営者の鍵で暗号化します
  • サーバーの記録はアカウントごとに分けて置き、アプリからは、そのアカウントのセッションでしか読み書きできません
  • 情報に触れられるのは、運営者と、上の 3 の会社とその委託先だけです。運営者は、このポリシーに従って情報を扱います
  • 情報を置く国と地域の制度を確かめたうえで、上の 3 の会社のサービスを使います。置く場所は、Cloudflare はアジア太平洋を指定（国は特定できません）、Sentry と PostHog は EU（ドイツ。日本と同等の水準の制度があると認められた地域です。AI の機能での処理は米国ほかでも行われます）、Anthropic、TypeSafe、Google は米国ほかです

7. 開示・訂正・削除などのご請求

あなたの情報の開示、訂正、利用の停止、削除、第三者への提供の記録の開示などを求めるときは、問い合わせのフォームからお知らせください。ご本人であることを確かめたうえで対応します。確かめ方は、ご請求の内容に応じてご案内します。手数料はいただきません。記録の訂正と削除は、アプリの中でもできます。

8. このポリシーの改定

このポリシーは、必要に応じて改定し、このページに改定日とともに載せます。情報を送る先や使い道が増えるなど大きく変えるときは、アプリの中でお知らせし、改めて同意が要るときは同意をいただきます。
