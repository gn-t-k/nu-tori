# 消費量は体重の傾向と食べた量から推定し、運動データは入れない

推定消費量は、MacroFactor と同じく体重の傾向と食べた量から推定し、1週間ごとに1日の目安を調整する。運動の記録やワークアウトの取り込みは入れない。ユーザーに求める操作を体重の記録と食事の記録の2つに保つため。運動データを入れないので、アクティビティリングも画面に出さない。
