# 無料版と広告を作らず、30日の無料体験のあとはサブスクにする

nu-tori は収入になる事業にする。支払いの登録なしに30日の無料体験ですべての機能を使えるようにし、そのあとは月額か年額のサブスクにする。無料版（LLM を呼ばない機能だけの版）と広告は作らない。無料体験が終わってサブスクがない人（サブスク切れ）には、体重の記録と過去の記録の見返しだけを残す。LLM を呼ばないので原価がほぼかからず、また買ったときにすぐ見直しが効くためである。

## 検討した案

- LLM の推定を抜いた無料版: 推定消費量は体重の傾向と食べた量の両方から出す（ADR-0007）ので、食べた量の推定がないと見直しも1日の目安も出せない。体験として納得できる絞り方にならない
- iOS 内蔵の LLM で推定する無料版: 推定の道が2つになり、ドメイン知識をサーバーに置く決まり（ADR-0011）とぶつかる。内蔵の LLM が賢くなるほど、有料の価値が薄れる。内蔵の LLM は、使うならサブスクの原価を下げる道具として考える
- 広告: 稼げる量を出すと体験を損ねる。記録の中身をどこにも送らない方針（ADR-0017）にも合わない
- 業界でよくある7日の無料体験: 体重が動くところまで使ってもらえない

## 再検討の条件

- 端末の中の LLM で、サーバーと同じ質の推定ができるようになり、無料版の原価がほぼ0になったとき
- 無料体験からサブスクに移る率が、業界の目安（健康・フィットネスの中央値 37.7%、多くは7日の体験の数字）を大きく下回り続けるとき
