# App Store Connect に書き込む鍵は GitHub Actions だけに置く

配信（版のページを作る、What's New と掲載情報を入れる、ビルドを付ける、審査に出す）には、役割 App Manager の鍵が要る。役割 Developer の鍵では、版を作ることも審査に出すこともできない（Apple の「Roles and access」の表。2026-11-09 に確かめた）。App Manager の鍵は GitHub Actions の配信のワークフローだけに置く。エージェントは、開発者が「OK」と言ったあとにそのワークフローを起動するだけにし、エージェント自身の鍵は役割 Developer のまま、スクリプトを通して読むだけに使う。

App Manager は値段と配信の地域も変えられるので、エージェントの手元に置くと、間違いのときに壊せるものが大きすぎる。ワークフローに置けば、書き込みの中身はレビューされたコードに固定される。

## 検討した案

- エージェントに App Manager の鍵を持たせ、`scripts/` のコマンドで書き込む: 手数は一番少ないが、値段を変えられる鍵をエージェントが持つ
- 鍵を増やさず、開発者が Mac で wizard を回して画面で入れる: 配信のたびに手作業が残る。配信は繰り返すので、割に合わない

根拠: App Store への配信の手作業を減らす設計の壁打ち（2026-11-09、`/grill-with-docs`）
