# triageラベル

スキルは、状態の役割5つと種類の役割2つで話す。このファイルは、それぞれの役割をこのリポジトリのIssue管理で実際に使うラベル名に対応づける。

スキルが役割に言及したとき（例：「エージェントに任せられる状態のラベルを付ける」）は、下の表の対応するラベル名を使う。

実際に使っているラベル名に合わせて、「このリポジトリでのラベル」の列を書き換えてよい。

## 状態

| mattpocock/skills でのラベル | このリポジトリでのラベル | 意味                                         |
| ---------------------------- | ------------------------ | -------------------------------------------- |
| `needs-triage`               | `needs-triage`           | メンテナによる判断待ち                       |
| `needs-info`                 | `needs-info`             | 報告者からの追加情報待ち                     |
| `ready-for-agent`            | `ready-for-agent`        | 仕様が固まり、エージェントに任せられる       |
| `ready-for-human`            | `ready-for-human`        | 人間が実装する必要がある                     |
| `wontfix`                    | `wontfix`                | 対応しない                                   |

`waiting` は状態の役割ではなく、状態のラベルに重ねて付ける。付ける場面は `docs/agents/issue-tracker.md` の「作業を先送りする」。

## 種類

スキルは種類を `bug` と `enhancement` の2つから選ぶと言うが、このリポジトリでは下の5つから選ぶ。

| mattpocock/skills でのラベル | このリポジトリでのラベル | 意味                                                                             |
| ---------------------------- | ------------------------ | -------------------------------------------------------------------------------- |
| `bug`                        | `bug`                    | 不具合。動くはずのものが動かない                                                 |
| `enhancement`                | `enhancement`            | 機能。ユーザーに見える新しい振る舞い                                             |
| （無い）                     | `growth`                 | 集客。見つけてもらい、入れてもらうための施策                                     |
| （無い）                     | `harness`                | 仕組み。人とエージェントが働く仕組み（スキル・文書・検査・CI・道具・コードの整理） |
| （無い）                     | `dependencies`           | 依存の更新。Dependabot が PR に付けるラベルと同じもの                            |

- 種類は、親の無い Issue に1つだけ付ける（`/wayfinder` のマップを含む）。サブ Issue は親の種類を引き継ぐので付けない
- ワークフローが立てる Issue には、ワークフローが種類を付ける

**Why:** ラベルが「誰が拾えるか」しか表さず、機能・集客・不具合・仕組みの Issue を見分けられなかった。機能と集客は違う時間軸で進むので、種類ごとに並べて見る（#1145）
