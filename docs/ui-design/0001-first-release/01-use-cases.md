## 検討して入れなかったもの

| 候補 | 入れない理由 |
|---|---|
| 運動の記録・ワークアウトの取り込み | 消費量は体重の傾向と食べた量から推定する（目安_2）。ユーザーの2操作を増やさない |
| 食品の検索・バーコード読み取り | 撮る・文章で書くで足りる。精度は量の修正で上げる（食事_6） |
| FoodNoms・MacroFactor との直接の連携 | ヘルスケアを介したやりとり（体重_3、目安_6、食事_10）で足りる |
| 体重の当てずっぽう入力 | 体重は厳密に測れる値なので、測った値だけを受け付ける |
| アカウント登録・課金 | 【仮置き】初回リリースの対象外 |
