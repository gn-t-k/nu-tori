## 1. 提供したいユーザー体験

**栄養を知らなくても、測って撮るだけで、体が目標に近づいていく手応えを持てるようになって欲しい。**

- Tさんには、2か月後に間に合いそうかが、考えなくてもわかるようになって欲しい
- Mさんには、今より少ない手間で、今と同じ精度の管理ができるようになって欲しい

## 2. 設計思想

トレードオフが起きたときは、上にあるものを取る。

1. **ユーザーの操作を増やさない。** 求める操作は「朝に体重を入れる」と「食べるときに撮る」の2つだけ。精度を上げる操作は、いつでもできるが、しなくてよい。操作を1つ増やすくらいなら、推定の精度が少し下がるほうを取る
2. **先回りして気を利かせる。** システムが知りうること（ヘルスケアの値、いつもの時刻、前日の値、以前の修正）は、ユーザーに尋ねる前に使う。尋ねるときは、初期値を入れた状態で尋ねる
3. **値の確かさに応じて受け付け方を変える。** 厳密に測れる値（体重）は測った値だけを受け付ける。測りにくい値（食事の量・栄養）は当てずっぽうでも受け付け、あとから直せる
4. **求められていないことは言わない。** AI のアドバイスは尋ねられたときだけ出す。通知は記録を忘れていそうなときだけ出す。淡々と記録したい人の邪魔をしない
5. **モードレス。** 撮ったあとの確認、目標案の選択、量の修正など、どの操作も途中でやめられ、あとからやり直せる。確認を済ませないと次に進めない作りにしない
6. **拡張性。** 課金、他アプリとの連携、写真以外の記録方法を、今の構造を壊さずに足せるようにしておく

## 3. 何をするものか（できること）

| できること | ぶら下がるタスク（`02-tasks.md`） |
|---|---|
| **食事を撮って記録する**（最重要） | 食事を撮る、撮り忘れた食事を文章で入れる、記録した食事を消す |
| 朝の体重を記録する | 今の体重を入れる、朝の体重を入れる、記録した体重を直す |
| 食事の量を直して精度を上げる | 料理の量を直す、栄養の内訳を開く |
| 体重と食事の傾向を見る | 体重の推移を開く、日付を選んでその日の食事を開く、週の振り返りを見る、目安の変更の理由を開く |
| AI に相談する | 質問を書いて送る、プリセットを選ぶ |
| 目標を立てる・切り替える | 増量か減量か維持かを選ぶ、目標案を選ぶ、期限と目標体重を自分で入れる |
| はじめる・やめる | サインインする、ヘルスケアへのアクセスを許可する、欠けた身体データを入れる、通知を許可する、アカウントを消す |

## 最重要

- **最重要タスク**: 食事を撮る
- **最重要オブジェクト**: 食事

理由: 体重はシステムが傾向をならして扱えるので、数日抜けても目安の調整は続く。一方、食事は撮り逃すとその日の摂取量が欠け、消費量の推定と1日の目安の両方が狂う。また「撮る」は1日に何度も起きる操作で、手間の差がいちばん効く。

優先度（`01-use-cases.md` の必須・推奨とあわせて）:

1. 食事を撮る（食事_1,2）
2. 朝の体重を記録する（体重_1）
3. 今日のここまでを知る（日、1日の目安との比較）
4. 傾向を見る、相談する、量を直す
5. 目標を立てる・切り替える（頻度は低いが、はじめに1回必ず通る）

## 習慣化を支えるもの

AI のアドバイスを尋ねられたときだけにしたので、習慣化は次の3つで支える。

- **手間がほぼゼロであること**: 開いたらすぐ撮れる。体重は前日の値が入った状態で待っている
- **手応えが見えること**: 体重は日々のブレではなく傾向の線で見せる。週の振り返りで、期限に間に合うペースかを伝える
- **忘れたときだけ知らせること**: いつもの時刻を過ぎても記録がないときだけ通知する

## 能動と受動の温度感

- ユーザーが能動的にする操作は2つ（体重・撮る）だけ。それ以外の情報（今日のここまで、傾向、目安の変更）は、アプリを開けば受動的に目に入る置き方にする
- 相談、量の修正、傾向の詳細は、能動的に取りに行く人だけが辿る奥の階層に置く

## 4. コンセプトイメージ

捨てる前提の落書き。開いた瞬間に撮れること、今日のここまでが一目でわかることだけを表している。

```
┌───────────────────────────┐
│ 今日  9/23         [人]   │
│ ┌───────────────────────┐ │
│ │                       │ │
│ │   カメラのファインダー    │ │  ← 開いたらもう撮れる
│ │                       │ │
│ │         ( ◯ )          │ │
│ └───────────────────────┘ │
│ 体重 72.4kg  ─╲_ 傾向      │  ← 未記録の朝はここが入力欄
│ 今日のここまで ■■■■□□ 1,240 │  ← 1日の目安との比較
│ ─────────────────────────  │
│ 07:12 [写真] おにぎり ほか    │
│ 12:30 [写真] 唐揚げ弁当      │
│ 21:40 [文]  残りご飯と唐揚げ  │
├───────────────────────────┤
│  今日     推移     相談      │
└───────────────────────────┘
```

【要確認】S3-1（開くと体重の入力欄が待っている）と S4-1（開くとカメラが起動している）は、どちらも「開いた瞬間」を取り合う。この絵では、今日のビューの上にファインダーを置き、体重が未記録の朝だけ体重の入力欄をファインダーより目立たせる案にしている。
