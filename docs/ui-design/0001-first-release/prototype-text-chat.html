文章と会話の見た目を見比べる

仕様「文章と会話」の前に、見た目で決めるものを並べた試作（捨てる前提。gn-t-k/nu-tori#412）。上の論点を選び、下のバーの ‹ › か矢印キーで案を切り替える。#<論点>-<案の番号>（例: #stream-2）で開ける。今のアプリ（main の TimelineComposer.swift、TimelineScreen.swift、MealCardView.swift、コミット 4e0f031）のタイムラインと入力欄の上に、書いて送る操作と会話を足して描いた。

例の日付は、今日が 9月24日（木）。値と文はすべて作ったもので、写真は色の四角で仮置きにした。決まっていることは論点ごとに灰色の段落に書き、どの案も守る。決まっていることのうち iOS の標準や別の文書と食い違うもの（5 の文字の大きさ）は、両方を描いた。5 の「少しずつ伸びる発言」は、案を開くと流れ、「もう一度流す」で何度でも流せる。
