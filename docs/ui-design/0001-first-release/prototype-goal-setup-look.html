目標を立てるの見た目を見比べる

仕様「目標を立てる」の前に、見た目で決めるものを並べた試作（捨てる前提。gn-t-k/nu-tori#506）。上の論点を選び、下のバーの ‹ › か矢印キーで案を切り替える。#<論点>-<案の番号>（例: #deadline-2）で開ける。今のアプリ（main の WeightNoticeCard.swift、TimelineScreen.swift、DayRingStrip.swift、WeightEntryControls.swift、コミット fb06d8a）のタイムラインの上に、目標の知らせのカードと、その場で広げる流れを足して描いた。

例の日付は、今日が 9月24日（木）。値はすべて作ったもので、目標体重と1日の目安は #32・#31 の追記の式で計算している。写真は色の四角で仮置きにした。決まっていることは論点ごとに灰色の段落に書き、どの案も守る。決まっていることを変える案には、案の説明に紫の線で印を付けた。カードは全体が見えるよう電話を縦に伸ばして描き、図の下に「1画面に収まるか」を書く。ある論点で見ている案は、ほかの論点の図と「通して触る」にもそのまま使う。
