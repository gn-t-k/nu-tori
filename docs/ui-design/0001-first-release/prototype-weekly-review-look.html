週の見直しと目標の経過の見た目を見比べる

見る順: まず「おすすめで通して見る」を1回見る。次に「見てほしい4つ」を1つずつ、下のバーで案を切り替えて選ぶ。ほかの 17 の論点は、エージェントがおすすめの案で決めた（「エージェントが決めたもの」を開けば、今までどおり案を見比べられる。おすすめの案には「おすすめ」と付けた）。

仕様「週の見直しと目標の経過」の前に、見た目で決めるものを並べた試作（捨てる前提。gn-t-k/nu-tori#576）。上の論点を選び、下のバーの ‹ › か矢印キーで案を切り替える。#<論点>-<案の番号>（例: #tlcard-2）で開ける。今のアプリ（main のコミット 21ce33e の TimelineScreen.swift、GoalSetupNoticeCard.swift・GoalDecidedCard.swift、DaySummarySheet.swift、WeightScreen.swift）の上に、振り返りのカード、1日の目安の変更の知らせ、週の振り返り、目標の画面、達成と期限の知らせを足して描いた。

例は凍結済みの見本と同じ人（減量、9月1日〜11月30日、74.0 → 70.0 kg）。値はすべて作ったもので、計算の細かいところ（見直しの式）は合わせていない。写真は色の四角で仮置きにした。決まっていることは論点ごとに灰色の段落に書き、どの案も守る。決まっていることを変える案には、案の説明に紫の線で印を付けた。どの論点も、1枚めの図は上の「条件」どおりに描き、2枚め以降は条件によらない決まった場面を描く。ある論点で見ている案は、ほかの論点の図にもそのまま使う（たとえば、タイムラインのどの図にも、いま見ているカードの形と知らせの文言が出る）。電話は全体が見えるよう縦に伸ばして描き、図の下にカードの高さを書く。用語は GLOSSARY.md に合わせ、凍結済みの見本の「消費量」は「推定消費カロリー」と書いた。
