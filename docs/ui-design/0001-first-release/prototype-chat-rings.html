いまの状態

例は Tさんの木曜の昼（12:40）。9時に「体重がまだ」の知らせが来ている。試すこと:

・知らせの中で体重を記録する（今日の丸にチェックが付く）
・撮るで食事を送る（今日の丸が伸びる）
・「唐揚げ食べた」と送る（食事として記録される）、「夜は何を食べればいい？」と送る（会話になる）
・丸を押してまとめを開き、日を送る。「タイムラインでこの日を見る」で戻る
・アカウントを開く

丸は1本の輪で、青が P、黄が F、緑が C の kcal。一周で1日の目安 1,850 kcal。丸を押すとまとめのシートが開き、‹ › で日を送れる。目標と週の振り返りは、まとめから開く想定で、ここでは開かない。
