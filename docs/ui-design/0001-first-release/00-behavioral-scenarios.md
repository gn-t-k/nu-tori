# 行動シナリオ（素描）

> プロダクトオーナーの構想から起こした素描。ユーザーに求める操作は「毎朝の体重の入力」と「食事の写真を撮る」の2つだけで、それ以外はシステムが引き受けるという前提で書いている。
> 各シナリオの【要確認】は、序盤ゲートまでに決める。

## S1 はじめて使う（Aさん）

1. Aさんは App Store で nu-tori を入れて開く
2. nu-tori はヘルスケアへのアクセス許可を求め、Aさんは許可する
3. nu-tori はヘルスケアから身長・体重・生年月日・性別・歩数を読み込み、読み取れた値を並べて見せる。Aさんは見るだけで先に進める
4. 体重が数か月前の値だったので、nu-tori は今の体重を尋ね、Aさんは入力する
5. Aさんは「減量したい」を選び、目標体重を入れる【要確認: 目標の聞き方。体重か、見た目か、期限を聞くか】
6. nu-tori は1日の目安（カロリーと栄養のバランス）を決めて、「あとは朝に体重を測って、食べるときに撮るだけ」と伝える
7. nu-tori は朝の体重と食事どきに通知してよいか尋ね、Aさんは許可する

## S2 毎朝、体重を測る（Aさん／Bさん）

1. Aさんは朝起きて体重計に乗る。nu-tori の通知をタップして開くと、体重の入力欄が前日の値で待っている。Aさんは数字を少し直して記録する
2. Bさんは体重計に乗るだけで、ヘルスケア経由で体重と体脂肪率が nu-tori に入る。Bさんは何もしない
3. 記録すると、nu-tori は体重の推移（1日単位のブレではなく傾向）を見せる
4. 体重を入れ忘れた日、nu-tori は昼までにもう一度だけ知らせる【要確認: 入れ忘れた日をどう扱うか】

## S3 食べるときに撮る（Aさん）

1. 昼、Aさんはコンビニのおにぎりとサラダを机に置き、nu-tori を開いてすぐ撮る（開いたらカメラが起動している）
2. nu-tori は写真から料理と量を推定し、カロリーと栄養を記録する。Aさんは確認せずに食べ始める
3. 撮影時刻から「昼食」として自動で振り分けられる
4. 夜、友人と外食する。Aさんは乾杯の前にテーブル全体を1枚撮る
5. 撮り忘れて食べ終えた。あとで空の皿を見て思い出し、何を食べたか一言だけ書く【要確認: 撮り忘れた食事の記録方法（文字・過去の写真・カメラロール）】

## S4 あとから精度を上げる（Bさん）

1. Bさんは作り置きの鶏むね肉とご飯を撮る
2. 夜、その日の記録を見ると、ご飯の量が「普通盛り（推定）」になっている。Bさんはご飯を「150g」に直す
3. nu-tori はその日の合計を再計算する
4. 翌日同じ作り置きを撮ると、nu-tori は前日の直しを覚えていて、はじめから 150g で推定する【要確認: どこまで学習するか】

## S5 今日の食事を知る（Aさん）

1. 夕食を撮ったあと、nu-tori は今日1日の食事がよかったかをひとことで伝える（例: 「タンパク質がもう少し欲しい日でした」）
2. Aさんは数字の意味を知らなくても、次に何を食べればいいかがわかる（例: 「明日の朝はゆで卵をひとつ足すと◎」）
3. Aさんは気になったとき、その日の食事の写真を並べて見返す

## S6 続ける（Aさん）

1. 1週間続けると、nu-tori は体重の傾向と食事の傾向を合わせて振り返りを見せる
2. 体重が減っていなくても、nu-tori は傾向と次にできることを伝え、Aさんは落ち込まずに続ける
3. 目標の見直しが必要なら、nu-tori が1日の目安を自動で調整し、Aさんにそれを伝える

## S7 Apple Watch の運動を反映する（Bさん）

1. Bさんがジムでワークアウトを記録すると、nu-tori はヘルスケアから消費量を読み込み、その日の目安に反映する【要確認: 初回リリースに入れるか】

## システム外の事柄（設計対象外）

- 体重計に乗ること、食事を用意すること、食べること
- ヘルスケアアプリ自体の操作、体重計とヘルスケアの連携設定
- 課金・アカウント管理【要確認: 初回リリースでアカウント登録をするか】
