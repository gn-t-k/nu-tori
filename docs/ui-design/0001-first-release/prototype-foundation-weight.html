土台と体重の見た目を見比べる

仕様「土台と体重」の前に、見た目で決めるものを並べた試作（捨てる前提）。上の論点を選び、下のバーの ‹ › か矢印キーで案を切り替える。どの案も凍結済みの 07-components/ の部品と DESIGN.md のトークンで描いた。例の日付は、今日が 9月24日（木）。

サインインの画面の同意

決まった同意の文を、サインインの画面にどう置くか。

決まっていること: 文面（「プライバシーポリシーを用意する」の決めたことの4）、置き場は「Appleで続ける」のボタンの真上、ボタンは標準のまま。名前とメールアドレスは求めない。失敗したときの理由はボタンの上に出す。

脚注今のサインインの画面の形のまま、ボタンの真上に同意の文を小さな字（Footnote）で置く。プライバシーポリシーのリンクは文の中だけにして、下の単独のリンクは消す。
カードアプリの名前を小さく上に寄せ、同意の文を白いカードに入れて本文の字（Subheadline）で読ませる。カードに「続ける前に」の見出しを付ける。
区切る同じ文を、送り先・AI・確かめることの3つに区切り、小さな見出しを付けて本文の字（Body）で並べる。「続けると、これらに同意したことになります。」だけをボタンの真上に残す。
2段最初の画面はアプリの名前と「始める」だけにし、押すとシートで同意の文と「Appleで続ける」を出す。1タップ増える。

サインインし直すときの画面

Apple の資格情報が取り消されていたとき（開いたときに分かる）と、サーバーがセッションを受け付けなかったとき（使わない期間 180 日で切れた、Apple からの通知で取り消した）に出すサインインの画面。

決まっていること: どちらもサインインの画面を出す。電波がなくて更新できないときは出さない。そのあいだも送り待ちは残し、同じアカウントで入り直したら送る。記録はサーバーに残り、同じ Apple ID で入れば戻る。

1行で添える初めてのサインインの画面と同じものに、理由を分けない1行を足す。送り待ちがあるときだけ、2文目を足す。
理由ごとに書き分けるApple の資格情報が取り消されたときと、セッションが切れたときで、1行を書き分ける。
記録の上にシート全画面のサインインに置き換えず、端末にある記録（タイムライン）を後ろに残したまま、閉じられないシートでサインインを求める。

電波がないときのアカウントの削除

電波がないときに「アカウントを削除」を押したときの、消せなかったことを示す1行の見せ方。

決まっていること: アラートを閉じ、アカウントのシートの削除の行の上に、消せなかったことを1行で出す。端末では何も消さない（「端末とサーバーの同期とオフライン時の振る舞い」の追記）。

見出しの位置削除のまとまりの見出しの位置（一覧の外、上）に、ふつうの文字の色で1行を出す。
一覧の中の行削除の行と同じ一覧の中に、印を付けた知らせの行を足す。
先回りして押せなくする電波がないあいだは、押す前から削除の行を押せなくし、上に理由を出す（決まっていることとは違う振る舞い）。

端末に記録が無いときの読み込み中

機種変更のあと、2台目、別のアカウントでサインインし直したあとなど、端末に記録が無いときに、記録を取り終えるまで出す読み込み中の見え方。

決まっていること: 読み込み中はタイムラインの場所に出す（DESIGN.md「待っている表示」）。端末に記録があるときは読み込み中を出さず、すぐ見せる。別のアカウントで入ったら、前のアカウントのものは端末からすべて消す。

真ん中に回る印タイムラインの場所の真ん中に回る印と文を出す。帯と入力欄はいつもどおりで、読み込み中も体重を記録できる。
骨組み記録が入る場所に、灰色の形（スケルトン）を並べる。回る印は出さない。
入力欄も待たせる真ん中の回る印は同じで、取り終えるまで入力欄を出さない。

サーバーが受け付けなかった記録に添える1行

送り待ちから送った体重をサーバーが受け付けなかったときの、1行の文言と置き方。新しい記録は消え、直した値は元に戻る。

決まっていること: 送り直さない。記録をサーバーの状態に戻し（新しく作ったものなら消し）、記録の位置に記録できなかったことを1行で出す（「端末とサーバーの同期とオフライン時の振る舞い」）。

記録の位置に1行消えた記録や戻った行と同じく右に寄せて、枠のない小さな字の1行を置く。
薄い行を残す消した記録の形を枠線だけの行で残し、値に打ち消し線を引いて、下に1行を添える。
アプリの知らせ全幅の白いカード（アプリからの知らせ）にし、入れ直すボタンを付ける。

電波がないときに記録した・直した体重

タイムラインと体重の画面の記録での見え方。

決まっていること: すぐ見せる。注記を付けない（DESIGN.md の Don't）。待っている表示はサーバーが処理しているあいだだけで、送れていないあいだは出さない。体重の傾向とそれを使う値は同期まで前のまま（傾向は「体重の傾向と記録忘れの通知」で扱う）。

何も変えない電波があるときとまったく同じに見せる。決まっていることのとおり。
送るまで時刻を薄く（対照）送り終えるまで、時刻だけを薄くする。DESIGN.md の Don't に反するので、並べて違いを見るためだけに置いた。

1日の丸の帯とタイムラインを、使い始めた日から始める

9月23日（水）に使い始めた人の、今週の帯と、タイムラインの一番上の見え方。

決まっていること: 使い始めた日はアカウントを作った日で、タイムラインはこの日から始まる。使い始める前の体重は推定に使うが、タイムラインには並べない（「ヘルスケアの読み書きの対応表」）。帯を使い始めた日から始めるかは、この試作で決める。

前の日は曜日だけ使い始める前の日は丸を描かず、曜日だけを薄く置く。前の週へは送れない。タイムラインの一番上に、使い始めた日を1行で書く。
前の日も空の丸使い始める前の日も、まだ来ていない日と同じ薄い空の丸にする。タイムラインの一番上には何も足さない。
前の日は点線の丸使い始める前の日は点線の丸にし、「記録を忘れた日」の空の丸と見分ける。タイムラインの最初の日の見出しに「使い始めた日」と添える。

1日に複数の体重記録があるとき

朝 6:48 に体重計のアプリ（例: Withings）がヘルスケアに書いた 72.3 kg を取り込み、7:12 に nu-tori で 72.4 kg を記録した日の、タイムラインと体重の画面（押した日の値、最近の記録）。

決まっていること: 取り込みはサンプル単位なので1日に複数ありうる。日の代表値はその日の最初の記録（計算に使う）。取り込んだ体重は出どころ（書いたアプリ）を持つ。入力欄から記録したとき置き換えるか新しい記録にするかは仕様で決める（ここでは新しい記録にした）。

並べて、代表の値を見せるタイムラインは1件ずつ並べる。体重の画面の上は代表の値（最初の記録）にし、その日のほかの記録を下に並べる。最近の記録は1日1行（代表の値）。
並べて、押した記録を見せるタイムラインは1件ずつ並べる。体重の画面の上は押した行の記録にする。最近の記録も1件ずつ（時刻を添える）。代表の値は見せない。
1日1行にまとめるタイムラインは代表の値の1行にまとめ、件数を添える。体重の画面で、その日の記録をすべて並べる。

体重の画面の一部（押した日の値と「直す」、最近の記録）

「土台と体重」の時点の体重の画面。傾向のグラフと目標までの道のりはあとの仕様で足すので、この2つだけで成り立つ形。

決まっていること: 「直す」でその場で値の欄になる。最近の記録の行を押しても、その行がその場で値の欄になる。最近の記録は新しい順に4週分まで。取り込んだ値を直しても、ヘルスケアの値は変えない（06-layout.md「体重の画面」）。

今の設計から引く07-components/weight から、傾向と目標のまとまりを抜いただけの形。
値を大きく、週で区切る押した日の値を真ん中に大きく出し、「直す」を灰色のボタンにする。最近の記録は週ごとの見出しで区切る。
記録だけの一覧上の値のまとまりを置かず、最近の記録の一覧で押した日の行を目立たせ、そこに出どころと時刻を添える。直すのはどの行も値を押す。

使い始める前の体重を、最近の記録に出すか

9月23日（水）に使い始めた人の、体重の画面の最近の記録。ヘルスケアには、その前の体重（体重計のアプリが書いたもの）がある。

決まっていること: 使い始める前の体重は推定に使うが、タイムラインには並べない（「ヘルスケアの読み書きの対応表」）。傾向のグラフに出すかは「体重の傾向と記録忘れの通知」で決める。

出さないタイムラインと同じく、使い始めた日からの記録だけを並べる。
区切って出す使い始める前の分を、見出しで区切って続けて並べる（4週分まで）。前の分は押しても直せない。

アカウントの画面

「土台と体重」で置く行（ヘルスケア、利用状況を送る、プライバシーポリシー、問い合わせ、アカウントの削除）と、削除のアラートの文。通知とカメラの行は、あとの仕様で足す。

決まっていること: ヘルスケアは許可の状態を出さず、用途ごとにまとめる。削除のアラートは「栄養と体重は残す」。削除を確かめるとき「記録はすぐに消え、エラーの報告と利用状況のデータは最長 90 日で消える」ことを伝える。利用状況を送るのオン・オフを置く（止める前に送った分は1年で消える）。問い合わせはアカウント ID を入れたフォームを開く。

用途で並べるヘルスケアを「読む」「書く」の中で用途ごとの行にする。90 日のことはアラートに入れる。
ヘルスケアへ潜る一覧には「ヘルスケア ›」の1行だけを置き、押すとシートの中で潜って種類と用途を見せる。90 日のことは削除の行の下の説明に置き、アラートは短くする。
種類で並べるヘルスケアを種類ごとの行にし、右に「読む」「書く」「読む・書く」を添える。用途はまとまりの下の説明に1文で書く。
