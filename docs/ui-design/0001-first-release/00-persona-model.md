# ペルソナモデル

> 実際に使ってほしい2人（Tさん・Mさん）をもとにした人物像。どちらもプロダクトオーナーからの聞き取りで、本人への調査はしていない。
> 「仮説」と書いた項目は、本人に確かめるか出荷後の検証で更新する。

## Tさん — 2か月後に上裸になる介護職の父親（主ペルソナ）

| 属性 | 内容 |
|---|---|
| 年齢・性別 | 50代・男性 |
| 家族 | 2人の子を育てている |
| 仕事と生活 | 介護職で、朝早くから夜遅くまで働く。食事の時刻は日によってずれる（仮説） |
| 体型 | 太っている |
| 本人が考える太る理由 | 皿洗いのときに子どもの残飯を食べてしまう |
| 目的と期限 | 2か月後、保育園の親の出し物で上裸になる。それまでに見た目を締めたくて焦っている |
| 今している取り組み | チョコザップに通い、プロテインを飲んでいる。ただ、何がどう効くのかはわかっていない |
| 栄養の知識 | ほぼない |
| 時間の余裕 | ほとんどない。アプリに使える時間は、食事の前の数秒と朝の数秒だけ（仮説） |
| iPhone のデータ | ヘルスケアの歩数は自動で入っている。身長・体重・生年月日は未登録かもしれない（仮説） |
| 求めること | 考えずに続けられること。2か月後に間に合うかを知りたい |

## Mさん — 増量と減量を繰り返すパワーリフター（副ペルソナ）

| 属性 | 内容 |
|---|---|
| 年齢・性別 | 30代・男性 |
| 家族 | 2人の子を育てている |
| 仕事と生活 | 9〜17時に自宅で IT 関係の仕事をする。ジムには週5回、1回1時間ほど通う |
| 目的 | 年に1回パワーリフティングの大会に出る。大会に合わせて、定期的に増量期と減量期を切り替える |
| 今の道具 | 食事の記録は FoodNoms、目標設定と進捗管理は MacroFactor |
| 栄養の知識 | 高い。マクロ栄養素に加えて、ビタミンやミネラルも気にする |
| iPhone のデータ | ヘルスケアに体重などが入っている（仮説。体重計と連携しているかは未確認） |
| 求めること | 記録の手間を減らしたい。ただ、精度は落としたくない。気になる食事は量を正確に直したい（仮説） |

## 2人の違い（ユースケースを広げる軸）

| 軸 | Tさん | Mさん |
|---|---|---|
| 栄養の知識 | ほぼない | 高い |
| 目標 | 1回きり、期限つきの減量 | 増量と減量を周期的に繰り返す |
| 精度へのこだわり | 低い。当てずっぽうでよい | 高い。あとから直したい |
| 時間の余裕 | ほとんどない | ある程度ある |
| 既存ツール | なし | FoodNoms、MacroFactor |

## 動作主体

- **ユーザー** — 上記ペルソナの総称
- **システム** — nu-tori。写真からの推定、ヘルスケアとの連携、目安の調整、フィードバック、通知を担う
