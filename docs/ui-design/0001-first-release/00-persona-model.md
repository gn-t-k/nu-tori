# ペルソナモデル（素描）

> 環境調査なしの素描。プロダクトオーナーの構想から起こした仮説で、出荷後の検証で更新する。
> 「仮説」と書いた属性は根拠がないので、`/grilling` や実ユーザーへの聞き取りで確かめる。

## 共通の前提

- iPhone を日常的に使い、ヘルスケアアプリに身長・体重・生年月日・性別などが入っている（入っていない人もいる）
- 栄養の知識はほぼない。PFC、カロリー収支、タンパク質量といった言葉は知らないか、知っていても使えない
- 過去に記録系アプリ（カロリー計算アプリ等）を試して、入力が面倒でやめた経験がある（仮説）

## Aさん — 減量したい、知識ゼロの会社員（主ペルソナ）

| 属性 | 内容 |
|---|---|
| 年齢・性別 | 28歳・女性 |
| 生活 | 平日は会社勤め。朝は慌ただしく、昼は社食かコンビニ、夜は自炊と外食が半々 |
| 目的 | 体重を 5kg 落として、見た目を引き締めたい |
| 栄養の知識 | ゼロ。「何をどれだけ食べればいいか」がわからない |
| iPhone のデータ | ヘルスケアに歩数と身長・体重（数か月前の値）がある。体重計はヘルスケアと連携していない |
| 続かない理由 | 食べたものを1品ずつ検索して量を入れるのが面倒で、3日でやめた |
| 求めること | 何も考えずに続けられること。今日の食事がよかったのか悪かったのかだけ知りたい |

## Bさん — 筋トレ中で、量を正確にしたいエンジニア（副ペルソナ）

| 属性 | 内容 |
|---|---|
| 年齢・性別 | 34歳・男性 |
| 生活 | リモートワーク中心。自炊が多く、同じ作り置きを何日も食べる |
| 目的 | 体脂肪を落としつつ筋肉を増やしたい（ボディメイク） |
| 栄養の知識 | 「タンパク質を多めに」くらいは知っているが、自分に必要な量は知らない |
| iPhone のデータ | ヘルスケア連携の体重計を使っていて、毎朝の体重と体脂肪率が自動で入る。Apple Watch でワークアウトを記録している |
| 続かない理由 | 写真だけの記録は精度が不安。かといって毎食グラムを量るのは続かない |
| 求めること | 普段は撮るだけで済ませ、気になる食事だけあとからご飯の量などを直して精度を上げたい |

## 動作主体

- **ユーザー** — 上記ペルソナの総称
- **システム** — nu-tori（写真からの推定、ヘルスケアとの連携、通知などを担う）
