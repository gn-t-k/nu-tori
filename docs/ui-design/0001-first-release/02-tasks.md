## 分岐条件メモ

- **ヘルスケアの許可**: 許可しない → 身体データはすべて手で入れる。体重の取り込み（体重_3）は働かない
- **身体データの欠け**: 欠けた項目だけを尋ねる。すべてそろっていれば尋ねない
- **体重の新しさ**: 【仮置き】ヘルスケアの体重が7日より古い → 今の体重を尋ねる
- **活動量**: 歩数が取れる → 歩数から見積もる。取れない → 3択で尋ねる
- **朝の体重**: その日の体重がヘルスケアから入った → 入力欄を出さない。入っていない → 朝に通知し、【仮置き】昼までに入らなければ1回だけ知らせる。それでも入らなければ空欄のまま
- **食事の記録手段**: 撮れた → 写真。撮れなかった → 文章
- **日々のひとことを出すタイミング**: 【仮置き】その日のいつもの最後の食事どきを過ぎてから撮った食事を最後とみなし、そのあとに出す
- **目安の調整**: 【仮置き】使い始めて7日未満、または直近の体重の記録が少ない → 調整を見送る
- **目標の切り替え**: 新しい目標を保存すると、前の目標は置き換わる。【仮置き】過去の目標を履歴として残すかは③で決める

## Delete の判定

- 食事の削除（食事_5）は、間違えて撮った記録を消す操作。メンタルモデルは「なかったことにする」なので D とする。誤操作に備えた取り消しは⑦で扱う
- 目標の切り替えは前の目標を消すのではなく置き換えるので U とする
