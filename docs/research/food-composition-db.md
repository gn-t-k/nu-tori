# 材料の栄養の根拠にする食品データベース（日本食品標準成分表ほか）

調査日: 2026-09-24
対象: Issue #24「日本食品標準成分表のデータの入手と利用条件」（wayfinder マップ #19 の子）。材料の「栄養の出どころ」（`docs/ui-design/0001-first-release/03-concept-model.md`）と、食事_8（栄養の内訳）の根拠になる食品データベースを、一次情報で確かめる。

> **確認の方法と限界**
> - 文部科学省の成分表のページ（mext.go.jp）、同「Q&A」PDF（令和8年3月版）、増補2023年の本表 PDF（第1章「説明」と第3章の資料「エネルギーの計算方法」）、文部科学省ウェブサイト利用規約とその別紙、食品成分データベース（fooddb.mext.go.jp）のヘルプ、消費者庁の栄養成分表示のページと「食品表示法に基づく栄養成分表示のためのガイドライン 第5版（令和7年4月）」PDF、USDA FoodData Central の API ガイド・データ種別の説明・Global Branded Food Products Database の説明、Open Food Facts の利用規約・データページ・API ドキュメント、GS1 Japan の JICFS/IFDB のページの**本文を直接取得して読んだ**。本文で確かめた主張は「本文で確認」と書く。
> - 増補2023年の本表 Excel（2026-03-27 更新版、1.9MB）を実際にダウンロードし、python3（openpyxl）でシート・列・値の表記を確かめた。「Excel で確認」と書く。ファイルはリポジトリに入れていない。
> - 本文の記述から推し量ったものは「本文からの読み取り」と書き、何から読み取ったかを添える。
> - 本文や関連ページを探しても記述が無かったものは「本文を探したが記述なし」と書く。
> - **取得できなかったもの**: Open Food Facts の API と facet ページは、この調査の間ずっと HTTP 503（"Page temporarily unavailable"）で、日本の製品のうち栄養成分が入力済みの件数は取れなかった（トップページの製品数は取れた）。USDA の API は DEMO_KEY のレート制限（429）に当たり、「natto」の検索結果は取れなかった（「miso」は取れた）。文部科学省の Q&A の 9-2〜9-5（栄養成分表示との関係）は PDF のテキスト抽出で回答部分が読めず、質問文しか確認していない。
> - 二次情報（解説記事、出版社の成分表本の紹介、ブログ）は使っていない。

## 結論の要約

- **最新版は「日本食品標準成分表（八訂）増補2023年」**（2023 年 4 月公表、2026-03-27 に正誤表を反映した Excel を更新）。2025 年版（九訂）は出ていない。文部科学省の Q&A（令和8年3月）に「現時点では、九訂に向けた作業は行っておらず」とある（本文で確認）。
- **入手**: 文部科学省のページから本表・アミノ酸・脂肪酸・炭水化物の各成分表を Excel（.xlsx）と PDF で直接ダウンロードできる。API や機械可読な配布（CSV/JSON）は無い。食品成分データベース（fooddb.mext.go.jp）は検索サイトで、データセットは「直接お渡しできません」（本文で確認）。
- **利用条件**: 「食品成分データは、ご自由に利用して頂けます」。論文・書籍・**アプリケーション等の二次利用**では「日本食品標準成分表（八訂）増補2023年から引用（又は出典）」と記載する。Q&A でも「成分表の一部又は全部利用に関する許諾等の手続きは不要」（本文で確認）。文部科学省ウェブサイト利用規約は公共データ利用規約（第1.0版）に準拠し、CC BY 4.0 互換。ただし規約の別紙に、成分表を「書籍（電子書籍を含む。）として有償頒布する際には、届出や著作権使用料の納付が必要となる場合がある」とある（本文で確認）。アプリへの組み込みはこの「書籍」に当たらないと読めるが、有料アプリにする場合は資源室（kagseis@mext.go.jp）に確認する余地がある（本文からの読み取り）。
- **収録**: 2,538 食品、18 食品群、可食部 100 g 当たり。本表だけでエネルギー（kJ/kcal）、たんぱく質・脂質・炭水化物（それぞれ組成に基づく値と従来値）、食物繊維、無機質 13 種、ビタミン 13 種（A・E は内訳あり）、食塩相当量、アルコールまで揃う（Excel で確認）。飽和脂肪酸は脂肪酸成分表編、糖類・水溶性/不溶性食物繊維は炭水化物成分表編にあり、本表には無い（本文で確認）。
- **食品の名前**: 5 桁の食品番号（食品群 2 桁＋3 桁）と索引番号を持ち、名称は Excel では「＜魚類＞　（あじ類）　むろあじ　開き干し」のように階層を全角スペースでつないだ 1 つの文字列（Excel で確認）。市販品（個別企業のブランド品）は収載しない方針（本文で確認）。
- **エネルギー**: 八訂から、アミノ酸組成によるたんぱく質×4、脂肪酸のトリアシルグリセロール当量×9、利用可能炭水化物（単糖当量）×3.75（または差引き法×4）、食物繊維×2、アルコール×7 などの FAO/INFOODS 方式に変わった。どの炭水化物項目を使ったかは食品ごとに異なり、Excel の「*」列で示される。増補2023年は計算法を変えていない（本文で確認）。**PFC × 4/9/4 で足し直しても成分表の kcal と一致しない**ので、1日の丸の P/F/C の kcal をどう出すかは決めごとになる。
- **他のデータベース**: USDA FoodData Central はパブリックドメイン（CC0 1.0）で API・一括ダウンロードがあるが、Branded Foods の市場国は米国とニュージーランドだけ（本文で確認）。Open Food Facts は ODbL（継承義務あり）、日本の製品は 44,903 件（本文で確認）、栄養成分が入力済みの割合は取得できず。
- **市販品の栄養表示の公開データ**: 消費者庁は表示を義務付けているが、表示値を集めた公開データベースは、消費者庁のページを探したが記述なし。JAN コードの商品情報データベース（GS1 Japan の JICFS/IFDB）は契約した事業者向けで一般公開されていない（本文で確認）。市販品の根拠は、パッケージの表示そのもの（義務 5 項目、許容差 ±20%）を読むのが現実的。

## 次の判断に効くこと（チケット #28「推定の仕組み」に向けて）

### 成分表をどう当てるか

- **同梱する**: 本表 Excel（2,538 行）を、食品番号・索引番号・食品群・階層に分けた名称・別名（備考から抽出）・tagname 付きの成分値・「*」の側・値の種別（実測／推計「( )」／微量「Tr」／未測定「-」）に起こした JSON にしてアプリに入れる。API が無く、値の更新は年に一度あるかないかなので、同梱で足りる。
- **当てはめは名前の検索ではなく候補の提示**: 材料名（AI の推定結果）から食品番号を選ぶ工程を、成分表の階層名・別名を索引にした検索と、AI による最終選択の 2 段にする。「ユーザーが食品を選んだり探したりするユースケースが無い」（概念モデル）ので、選択は内部で行い、材料には食品番号・版名・当てはめの確度を「栄養の出どころ」として持つ。
- **調理状態を合わせる**: 「生」「ゆで」「焼き」などの細分と重量変化率を持つので、写真に写った料理（調理後）に対しては調理後の細分を優先して当てる。惣菜は 18 群の「調理済み流通食品類」（55 食品）を代替として使える（Q&A 10-1 がその用途を認めている）。
- **消費者庁の「適切ではない事例」を外し方の基準にする**: 主原料・部分割合・調理法が違う食品に成分表の値を流用しない（コロッケ、あんパン、ポテトチップスの例）。当てはめの確度をこの観点で下げる。
- **エネルギーの扱いを決める**: 成分表の kcal（組成に基づく）をそのまま使い、P×4・F×9 を引いた残りを C 側に見せる（案 a）か、PFC × 4/9/4 で kcal も足し直す（案 b）か。市販品の表示値と混ぜるなら案 a が整合しやすい。
- **未測定「-」を 0 と混同しない**: ビタミン・ミネラルの内訳（食事_8）では、「-」は「不明」として合計から外すか、不明があることを示す。「(0)」「Tr」は 0 扱いでよい。
- **飽和脂肪酸・糖類を出すなら別編を結合する**: 本表には無い。脂肪酸成分表編・炭水化物成分表編の Excel（同じ食品番号）を結合すれば揃うが、収載食品は本表より少ない。
- **出典表示**: 情報画面に「日本食品標準成分表（八訂）増補2023年から引用（又は出典）」と、nu-tori 側で当てはめ・換算を行っている旨を載せる。有料化するときは、規約の別紙（有償頒布の例外）について資源室に確認する。

| D. USDA FoodData Central を素材の補完に使う | CC0、API・一括ダウンロード、市場国は米国・NZ | ライセンスが最も緩い。成分表に無い海外食材の補完に使える | 日本の市販品は無い。単位・項目の定義が成分表と異なる |
| E. JICFS/IFDB など商用の JAN データベースと契約する | GS1 Japan の利用形態 | 市販品を網羅できる可能性 | 一般公開されず、契約が要る。栄養項目の有無も未確認。初回リリースの規模に合わない |

初回リリースで「市販品や飲みものは材料が 1 つの料理として扱う」（概念モデル）方針と組み合わせるなら、**成分表（A）を基本にし、市販品は表示の読み取り（B）で上書きできるようにする**のが、出典が明確で利用条件の負担が無い組み合わせになる。C は帰属表示と継承義務を受け入れられるか、D は日本の食品への当てはまりが薄いことを踏まえて、後から足すかを判断する。
