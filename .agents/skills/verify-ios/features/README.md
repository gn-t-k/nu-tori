# アプリの機能の地図

iPhone アプリの、ユーザーから見た機能の索引。確かめる前にここを読み、触れた機能のファイルを手順として使う。機能がどこにあり、ユーザーがどうたどり着くかを知りたいときの索引でもある。

## 前提

- Mac のセッションで回す。手順の `$S`・`$run` は `../SKILL.md` のとおり
- UI テストの行は `$S/ui-test.sh` で回す。手で動かす行は、`start.sh` で作った回で、`doctor.sh` が全部 `ok` を返してから動かす
- 手で動かす行は、行ごとに `launch.sh` で場面を開き直す。前の行の記録に頼らない
- 場面の記録は偽の同期サーバーの作り物。画面に開発者の健康データは出ない

## 動かし方の決まり

- 場面と起動の値は、書いたとおりに渡す。時計は `launch.sh` の既定（`../SKILL.md` の「起動」）で、変えるときは行に書いてある
- 押す要素は accessibility identifier で探す。identifier の無いものは、画面に出る文字で探す
- 結果は、操作のあとの `snapshot_ui` の要素と、`shot.sh` で撮った画面で読む

機能のファイルの形は `../MAP-FORMAT.md` にある。足す・直すときはそれに従う。

## 機能

- [サインインとアカウント](./account.md): Apple でサインインしてタイムラインに入り、アカウントの画面からサインアウト・削除するとサインインの画面に戻る
- [体重記録](./weight-record.md): 入力欄と知らせから体重を記録してタイムラインに出す。体重の画面で直す。電波が無い・受け付けられなかったときの見え方。ヘルスケアの体重の取り込み
- [食事の記録と推定](./meal-estimation.md): 選んだ写真の食事が推定されてカードに出る。食事の画面で時刻と料理を直す・足す・消す
- [送った文章と返事](./reply.md): 書いて送ると読んでいますのあとに返事が届く。食事の文章、会話として送り直す、作れなかった返事を送り直す
- [目標と週の振り返り](./goal.md): 知らせから目標を決めると目安と比べる丸になる。週の振り返りと目標の画面を開く。目標を切り替える
